=== Readout from trust task force: Scott

Last week’s meeting focused on finalizing the parameters needed for the Trust Registry action in the CAWG Identity Assertion. We agreed to move forward with the four standar parameters specified in the Trust Over IP’s Trust Registry Query Protocol (TRQP) (`entity_id`, `action`, `resource`, and `authority_id`). We agreed to adopt CAWG-based definitions within our newly Definitions Task Force.

We also walked through a reference architecture of a https://github.com/sankarshanmukhopadhyay/cawg-trqp-verifier-refimpl/tree/main/docs[CAWG/TRQP test scenario (Photography contest)] with Sankharshan Mukhopadhyay.

We briefly covered the what should replace the global trust model when the current use of S/MIME certificates sunsets after March 2027. The preliminary feedback is to focus on content-signing certificate Object Identifiers (OIDs).
